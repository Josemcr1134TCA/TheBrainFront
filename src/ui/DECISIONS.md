# The Brain · registro de decisiones del design system

Este archivo es la **única fuente de verdad** de las decisiones de diseño. Léelo completo al empezar una sesión y actualízalo al terminar.

## Cómo se usa

1. Antes de construir, lee este archivo. Una decisión **confirmada** no se vuelve a preguntar ni se contradice.
2. Una decisión **por confirmar** no se trata como cerrada: si tu trabajo depende de ella, detente y pregunta (ver D-009).
3. Cuando la persona decide algo nuevo, agrégalo aquí **primero**, con el siguiente identificador libre.
4. No hay espejo en Notion (D-036): este archivo es el único registro. Si alguien necesita verlo desde Notion, una persona enlaza este archivo.
5. Nunca borres una decisión. Si cambia, escribe una nueva que diga cuál reemplaza.

Estados: `confirmada` · `por confirmar` · `reemplazada por D-0XX`.

## Deuda conocida

- No hay servicio de tema en Angular (D-026) ni marco de la aplicación construido (barra superior y menú lateral, ya definidos en la v6 y en el prototipo v5, D-046). La app solo tiene un marco provisional.
- Dentro de `docs/reference.src.html`, los códigos hexadecimales de las muestras de color y las cifras de contraste (por ejemplo «5.2:1») están escritos a mano. Pueden divergir de `tokens.json`. Pendiente generarlos desde los tokens y calcular el contraste en el validador (paso 2).
- El documento de referencia sigue usando las clases `tb-*`, no utilidades de Tailwind. Es una referencia visual; la app usa los tokens de `theme.css`.
- **La sección de formularios no se ha visto renderizada.** El entorno donde se construyó no tiene navegador y la red bloquea su descarga. Se comprobó de forma estática: ids únicos, `label for` y referencias ARIA que apuntan a algo que existe, variables CSS definidas y sin emoji. Falta revisar a ojo el aspecto en claro y oscuro y en pantalla angosta.
- Formularios sin definir: cambios sin guardar al cerrar una hoja o una página.
- Las vistas previas usan nombres de fabricantes anonimizados («FABRICANTE A…», D-030) y cifras de ejemplo. Son datos de muestra, no reglas.
- El comportamiento del botón de tema se probó con un DOM simulado (24 comprobaciones sobre las dos páginas), pero el cambio visual de colores no se ha visto en un navegador real.
